# LLM judge evidence

This folder contains the complete judge-evaluation record for the selected 20 model-backed 0/1 Knapsack conversations.

## Contents

- `a2_selected_20.json`: the exact 20-conversation dataset used for human and model judging.
- `conversations/a2_selected/`: the same conversations as individual JSON files.
- `personas/personas_knapsack.json`: the eight simulated-learner personas.
- `generation/`: a preserved copy of the conversation generator, helper functions, and exact simulated-learner system prompt.
- `human_labels.json`: 40 independent human labels, two criteria for each conversation.
- `prompts/`: every submitted judge-prompt version, including the revised v3 C1 prompt.
- `judge_results/`: model verdicts and agreement calculations.

Tutor turns came from the running CUI. Learner turns were generated by a separate simulated-learner model following the assigned persona. Human labels were completed independently before judge results were used for agreement analysis.

The canonical runnable generator remains `testing/generate_conversations.mjs`; the copy under `generation/` is retained to satisfy evaluation provenance requirements.
